# Proposed single-task pilot scope policy

This file describes the proposal only. Its digest is not an installed policy or execution grant.
Test-only changes to the two named files and pilot result report; no application source changes,
dependency changes, MCP inheritance, secret access, staging, merge or automatic repair tasks.
Model workers receive role-specific filesystem/tool controls. Trusted coordinators own separately
bound repository/Beads/delivery operations. Existing account only, bounded attempts and no paid API
experiments. Exact task identity, test environment, source, material and installed policy must be
resolved and independently reviewed before owner approval can authorize a live managed run.
