## Task requirements

Define and implement frontend artifact viewer patterns for evidence generated by agents and tools. Browser screenshots are the first example, but the pattern should generalize to snapshots, generated files, reports, logs, and future diffs.

This task should use existing artifact data where available and avoid backend contract changes.

## Stack constraints

Use Next.js App Router, shadcn/ui, Tailwind CSS, and TypeScript. Do not introduce new UI libraries, change data contracts, or add backend logic.

## Implementation plan

1. Inventory current artifact display behavior for browser screenshots and workspace files.
2. Define artifact card anatomy: title, type, source, status, size, truncation, created time, and actions.
3. Define viewer patterns by type:
   - image/screenshot viewer
   - snapshot/text viewer
   - report/log viewer
   - generated-file viewer/download affordance
   - future diff viewer shell
4. Ensure artifacts open in-app rather than surprise new tabs.
5. Define empty, loading, unavailable, truncated, and failed states.
